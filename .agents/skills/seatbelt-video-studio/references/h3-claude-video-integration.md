# Claude Video and MiniMax H3 integration

`ecommerce-video-studio` governs the common production flow. `seatbelt-video-studio` supplies seatbelt category constraints; H3 and reference-video tools are execution adapters.

## Reference-video analysis

Use `claude-video` only to inspect reference videos. It downloads or reads a source, extracts selected frames, obtains captions or a transcript, and returns evidence for a `reference` or `hybrid` brief. It does not generate media and must not replace human review.

Keep the original file in the job's `assets/source/`. Capture hook timing, spoken words, shot boundaries, camera movement, visible actions, audio rhythm, and transition cues. Translate these into a neutral structure summary in the brief and shot plan. Never copy a reference person's identity, logo, product, wording, or unsupported claim.

The local runtime requires `ffmpeg` and `yt-dlp`. Native captions are preferred; Whisper is a fallback only when captions are unavailable. If dependencies are missing, mark analysis as pending rather than pretending the video was inspected.

## H3 generation

Use MiniMax-H3 `Ref2VA` through DFCine's `h3.ref.cloud`. H3 prompt-writing compiles the shot contract; DFCine remains the execution and result-tracking layer.

Assign references by role after inspecting the actual DFCine input labels:

- product identity: standalone approved product image;
- installed geometry and target scene: approved installed-state image only for an installed or worn depiction;
- optional motion/audio reference: only when supplied and approved;
- prompt: one primary action, one motivated camera move, explicit endpoint.

Every new MiniMax H3 shot must use `audio_mode: native` and generate audible dialogue or off-screen narration. Put the exact spoken line in `dialogue`; put speaker role, emotion, voice delivery, ambience, sound effects, and target timing in `audio_direction`. A product-detail shot with no visible speaker still gets its assigned line as off-screen narration. This native audio guides performance and mouth movement even if it is not used in the final mix. Keep important advertising text and CTA as post-production overlays.

Final narration is generated by the user outside Codex with Seed Audio 1.0. Prepare the separate handoff brief before H3 generation; keep exact wording and intended phrase timing identical between H3 and Seed Audio. After H3 review, import the user's Seed Audio file for the final timeline.

For a shot depicting the product installed or worn on a belt, state that it is already installed at the first frame; the belt stays continuous, flat, and aligned; the pad and plush remain one assembly; and no installation or adjustment action occurs. For a standalone or handheld depiction in any scene, describe that state explicitly and avoid implying installation or wearing. In all cases, preserve SKU identity, avoid unsupported safety claims, price, logo, and watermark, and leave room for post subtitles and CTA when planned.

## Review boundary

Prepare prompts and dry-run DFCine mutations before any paid or GPU run. Generate one preview per shot, then human-review audio, lip sync, product geometry, belt continuity, and endpoint stability. Do not auto-retry. Record accepted results before post-production.
