# 中国左舵乘用车：座位、安全带与镜头空间规则

## 适用范围与权威顺序

本规则用于本项目中的中国道路常见左舵轿车/乘用车视觉生成与审查，尤其是前排三点式安全带和护肩套场景。若具体车型的用户实拍、车辆说明书或明确可见结构与通用规则不同，以该车型资料为准并记录例外；不得把右舵车、镜像自拍或生成模型的错误结构混入默认规则。

依据顺序：具体车型真实结构图与用户确认 > 同车型官方说明书/实拍 > 本规则 > 保守推断。

项目车辆结构参考位于：`production/assets/vehicle-references/china-lhd-mercedes-sedan/source/`。这些图只作为中国左舵奔驰轿车的座位、方向盘、B 柱、安全带与中控空间参考，不作为产品身份参考。

## 固定车身坐标

所有判断先使用车辆自身坐标，不使用“画面左边/右边”：

- `vehicle-left`：车辆前进方向的左侧。
- `vehicle-right`：车辆前进方向的右侧。
- `outboard`（外侧）：靠近该座位同侧车门、侧窗和 B 柱的一边。
- `inboard`（内侧）：靠近中控台、中央扶手和另一前排座位的一边。
- 中国道路机动车实行右侧通行；本项目默认中国市场常见左舵车。
- 前排主驾驶位在 `vehicle-left`，方向盘、仪表和踏板位于主驾驶前方。
- 前排副驾驶位在 `vehicle-right`，其前方为副驾仪表台/手套箱区域，不应出现第二套方向盘、仪表或踏板。
- 中控台位于两座之间：主驾的右侧、副驾的左侧。

## 前排三点式安全带的共同结构

每个前排座位的三点式安全带均有：外侧上部导向/肩部起点、斜跨胸前的肩带段、内侧锁舌与锁扣结合点、横跨骨盆的腰带段、外侧下固定点/卷收器路径。生成画面中至少要让可见部分符合这一连续拓扑，不得创造独立带段。

- 上部起点：乘员该座位的 `outboard` B 柱上方或座椅集成导向点。
- 肩带：从外侧上方经过同侧肩部，斜跨胸前，到达对侧内侧髋部附近的锁扣。
- 锁扣：位于座位 `inboard` 一侧，靠近中控台；不得放在车门一侧。
- 腰带：从内侧锁扣横跨左右髋骨/骨盆区域，回到座位外侧下固定点。
- 安全带不得从颈部正中、腋下、背后或腹部高位绕行；不得扭转、悬空、中断、分叉、复制或穿过身体/座椅。

## 锁扣与锁舌的结构、位置和样式

本项目将两个容易混淆的部件严格区分：

- `buckle / 锁扣总成`：固定在座椅内侧、靠中控台的接收部件。用户提供的奔驰参考样式为低矮黑色壳体，顶部有醒目的红色释放按钮，通常从座垫内侧与中控台之间露出；底部通过短支座或固定结构连接车身/座椅。它不悬挂在肩带上，也不位于车门侧。
- `latch plate / 锁舌`：可随织带移动的金属插片，系带时插入锁扣。未使用时，锁舌通常随外侧 B 柱附近的织带悬挂；不得把锁舌画成红色按钮盒，也不得让锁扣沿织带移动。

系好安全带后，内侧髋部应形成一个清楚的连接节点：斜向肩带与腰带在锁舌处汇合，锁舌插入靠中控台一侧的黑色锁扣；红色释放按钮朝上或朝向乘员可按压的方向。按钮可以因人物、衣物、座垫或镜头裁切而只露出一部分，但锁扣不应漂浮在座面中央、埋进人体、穿进中控台或出现在外侧车门旁。

项目样式参考：`production/assets/vehicle-references/china-lhd-mercedes-sedan/source/front-seat-inboard-buckle-closeup-v1.png`。该图定义本奔驰车内视觉的锁扣外观与相对位置；不同车型可有合理外观差异，但仍须保持“内侧固定锁扣 + 外侧织带活动锁舌”的功能拓扑。

## 主驾驶安全带：车身左侧座位

- 人在主驾时，方向盘应在其正前方；车门和左 B 柱在其身体左侧，中控台在其右侧。
- 肩带上端从乘员左后上方的左 B 柱/左外侧导向点开始。
- 肩带经过乘员左肩，斜跨胸部，到乘员右侧髋部、靠中控台一侧的锁扣结束。
- 腰带由右侧内侧锁扣横跨骨盆，回到左侧外侧下固定点。
- 护肩套若装在主驾肩带上，应位于左肩接触区至上胸，长轴与“左上外侧 → 右下内侧”的肩带方向一致。

## 副驾驶安全带：车身右侧座位

- 人在副驾时，车门和右 B 柱在其身体右侧，中控台在其左侧；前方不应有方向盘。
- 肩带上端从乘员右后上方的右 B 柱/右外侧导向点开始。
- 肩带经过乘员右肩，斜跨胸部，到乘员左侧髋部、靠中控台一侧的锁扣结束。
- 腰带由左侧内侧锁扣横跨骨盆，回到右侧外侧下固定点。
- 护肩套若装在副驾肩带上，应位于右肩接触区至上胸，长轴与“右上外侧 → 左下内侧”的肩带方向一致。

## 主驾与副驾的镜像关系

主驾和副驾不是两条同方向的斜带，而是围绕中控台近似镜像：两条肩带都从各自靠车门的外侧高点，斜向各自靠中控台的内侧低点。锁扣均位于两座之间，但分别贴近各自座椅内侧；上部导向点则分居左右 B 柱。

未坐人时，安全带通常回缩在座位外侧 B 柱附近，带体近似竖直，锁舌悬在外侧带体上；座位内侧锁扣仍留在中控台旁。不得把未使用安全带横跨空座并扣到错误一侧，除非真实参考明确如此。

## 镜头方向与画面左右

不得直接把“图片左/右”当作“车辆左/右”。必须先判断相机朝向，并警惕手机自拍或平台预览的水平镜像。

- 后排相机朝前、未镜像：主驾通常在画面左，副驾在画面右。主驾肩带画面方向约为左上到右下；副驾约为右上到左下。
- 仪表台/挡风玻璃相机朝后、未镜像：主驾通常在画面右，副驾在画面左；画面斜线方向与后排视角相反。
- 从主驾侧拍向副驾：方向盘可作为近端边缘前景，但必须明显属于相机侧主驾区，不能像安装在副驾正前方。
- 从副驾侧拍向主驾：副驾仪表台/车门可作近端前景，方向盘应在被摄主驾前方。
- 自拍图可能左右翻转。判断时优先看方向盘—仪表—踏板组合、中控台、B 柱上导向点、锁扣位置、车门侧后视镜，不以人脸朝向或单一斜带方向下结论。

## 第一人称与第三人称的画面镜像换算

车辆结构本身不会因镜头改变：主驾永远是车身左侧，主驾安全带永远是左 B 柱 → 左肩 → 右髋中控侧锁扣；副驾永远是车身右侧，副驾安全带永远是右 B 柱 → 右肩 → 左髋中控侧锁扣。改变的是这些固定部件落在成片画面的哪一边。

### “第三人称”的项目默认含义

本项目中，若提示词只写“第三人称”而未说明机位，一律解释为“第三人称正面”：相机位于被摄前排人物前方的仪表台/挡风玻璃区域，朝车尾拍摄人物正面，且 `software_mirror = no`。后排朝前拍必须明确写成“第三人称后方/后排跟随视角”，侧面斜拍必须明确相机位于主驾侧或副驾侧。不得再用未限定的“第三人称”描述后排或侧拍。

### 当前任务的强制机位锁

在 `third-passenger-lulu-20260816` 的分镜视觉资产阶段，所有包含前排人物与安全带的测试图，一律使用第三人称正面机位；在用户明确批准解除前，不得使用主驾侧斜拍、副驾侧斜拍或后排朝前机位。其目的不是否认其他机位的物理可能性，而是先用一个无歧义坐标系统验证主驾、副驾、安全带和产品关系。

### 主驾第一人称向前看

相机位于主驾头部/胸部附近并朝车辆前方，未镜像时：车辆左门、左后视镜、左 A/B 柱在画面左；方向盘和仪表位于画面中央偏左；中控与副驾区域在画面右。这类机位通常看不到主驾自己的完整肩带关系，不能作为主驾人物佩戴图的唯一参考。

### 第三人称正面看主驾

相机位于主驾前方、方向盘/仪表台/挡风玻璃附近并朝车尾拍摄主驾正面，未做软件镜像时：

- 车辆左侧（主驾门、左窗、左 B 柱）落在画面右侧；
- 车辆右侧方向（中控台、副驾方向）落在画面左侧；
- 主驾人物位于画面右侧或右中区域，方向盘位于其正前方并通常也在画面右中区域；
- 人物解剖学左肩落在画面右，人物右髋内侧锁扣落在画面左下；
- 主驾肩带应从画面右上经过人物左肩，斜向画面左下的中控侧锁扣，即右上 → 左下。

若所谓“第三人称正面主驾图”中，主驾门/B 柱在画面左、主驾人物与方向盘也在画面左、肩带左上 → 右下，则它实际上更像后排朝前或侧面机位，不符合第三人称正面合同。

### 第三人称后方看主驾

相机位于后排并朝车辆前方拍摄，未镜像时：车辆左侧仍在画面左，主驾在画面左，左 B 柱和人物左肩在画面左，主驾肩带为画面左上 → 右下。此构图在物理上可以正确，但必须标为 `camera_origin = rear seat`、`camera_facing = forward`，不得标成第三人称正面。

### 副驾侧斜拍主驾

相机位于副驾或中控侧、向左斜拍主驾时，透视可能接近后方视角或正面视角，画面左右不能仅靠“第三人称”推断。提示词必须逐项指定主驾门/B 柱、中控、方向盘和内侧锁扣的预期画面位置；若生成结果与合同不一致，标记 `camera_contract_mismatch`。

### 主驾第一人称向右看副驾

用户提供的奔驰内饰结构图属于主驾座位第一人称参考：相机位于主驾头部/胸部附近，朝车辆前方或向右转看副驾。向右看副驾时，通常形成：

- 副驾中控内侧较靠画面左或左下；
- 副驾右车门、右侧窗和右 B 柱较靠画面右；
- 若副驾有人，其右肩/外侧通常落在画面右，左髋内侧锁扣落在画面左下；
- 副驾肩带在画面中通常表现为右上 → 左下。

这不是水平翻转，而是相机仍与乘员大体同向、从主驾侧向副驾观察所形成的画面投影。

### 第三人称正面看副驾

当相机位于副驾前方、仪表台/挡风玻璃一带并朝车尾拍摄人物正面时，相机与车辆前进方向相反。未做软件镜像的原始画面应表现为：

- 车辆右侧（副驾车门、右窗、右 B 柱）落在画面左侧；
- 车辆左侧方向（中控台、主驾方向）落在画面右侧；
- 人物右肩落在画面左，人物左髋内侧锁扣落在画面右下；
- 副驾肩带在画面中表现为左上 → 右下。

因此，“第一人称主驾向右看副驾”和“第三人称正面看副驾”在画面左右上近似互为镜像，但车辆语义完全相同。不得为了匹配参考图的像素位置，把副驾误改成主驾结构。

### 第三人称后方看前排

当相机位于后排并朝车辆前方拍摄时，相机与车辆方向相同：车身左侧在画面左，车身右侧在画面右；副驾位于画面右，其肩带通常为右上 → 左下。

### 软件水平翻转

自拍预览或后期 `horizontal flip` 会在以上任一机位基础上再次交换画面左右，但方向盘标识、文字、仪表和车内结构也会一起翻转。若无法确认是否软件镜像，标记 `mirror_state_unknown`，不得只依据安全带斜线判座位。

### 生成合同必填字段

每张人物车内图必须明确四项：`camera_origin`（主驾/副驾/后排/仪表台前方）、`camera_facing`（朝前/朝后/向左/向右）、`software_mirror`（yes/no）、`expected_image_mapping`（车门、B 柱、中控、锁扣分别位于画面哪侧）。缺少这些字段的提示词不得进入正式生成。

主驾第三人称正面模板：`camera_origin = 主驾前方仪表台/挡风玻璃区域；camera_facing = 朝车尾；software_mirror = no；expected_image_mapping = 主驾左门/左B柱/人物左肩在画面右，中控/人物右髋锁扣在画面左，方向盘在主驾正前方的画面右中，肩带画面右上 → 左下。`

## 座位判定最小证据链

审查任何人物车内图时，按以下顺序记录：

1. 方向盘、仪表、踏板属于哪一侧；由此确定主驾。
2. 中控台相对人物位于哪侧；验证主驾/副驾判断。
3. 人物同侧车门和 B 柱位于哪侧；确定 `outboard`。
4. 安全带上端是否从该座位外侧 B 柱进入。
5. 肩带是否经过同侧肩并斜向内侧髋部锁扣。
6. 锁扣是否在中控侧、腰带是否回到外侧下固定点。
7. 锁扣是否为固定在座椅内侧的黑色接收件，红色释放按钮方向合理；锁舌是否随织带插入锁扣，而非与锁扣混为一体。
8. 最后才检查护肩套的位置、比例、遮挡和产品身份。

若 1–3 无法从裁切画面确定，则标记 `seat_role_ambiguous`，不得仅凭斜带方向声称是主驾或副驾；使用相邻镜头、未裁切母图或用户确认消除歧义。

## 生成提示词硬约束

每个前排人物镜头应明确写出：`中国左舵轿车`、人物座位角色、车辆外侧/内侧、方向盘所在位置、B 柱肩带起点、跨过哪侧肩、内侧锁扣位置、相机所在位置与朝向、是否镜像。

主驾模板：`中国左舵轿车，人物坐在车身左侧主驾驶位，方向盘和仪表在人物正前方；安全带从人物左后上方 B 柱出发，经过左肩斜跨胸前，扣入人物右髋靠中控台一侧的锁扣。`

副驾模板：`中国左舵轿车，人物坐在车身右侧副驾驶位，前方无方向盘；安全带从人物右后上方 B 柱出发，经过右肩斜跨胸前，扣入人物左髋靠中控台一侧的锁扣。`

## 直接失败条件

- 中国左舵车中方向盘出现在副驾正前方，或同一前排出现两套方向盘/仪表。
- 安全带从座位内侧中控方向高处起始，或扣到外侧车门方向。
- 主驾带从右肩起、副驾带从左肩起，且没有车型级特殊证据。
- 上端导向点、肩带、锁扣、腰带无法构成同一条连续三点式安全带。
- 锁扣漂浮、重复、装在车门外侧、随织带悬挂，或把红色释放按钮错误生成在活动锁舌上。
- 主副驾两条安全带平行同向而非镜像，或安全带穿过方向盘、座椅头枕、车门饰板、人体内部。
- 护肩套位于锁扣以下、腰带上、腹部、座椅外侧空带段，或其方向与肩带中心线明显不一致。

## 外部依据

- 《中华人民共和国道路交通安全法》第三十五条规定机动车实行右侧通行；第五十一条规定驾驶人、乘坐人员应按规定使用安全带。
- GB 7258-2017《机动车运行安全技术条件》为现行强制性国家标准，涵盖机动车安全防护装置等运行安全要求。
