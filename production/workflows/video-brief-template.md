# 视频任务提示词模板

把下面「模板」整段复制给 Claude 或 Codex，填写【】里的内容；留空的项由 AI 补。填写时商品、人物、场景直接写素材库页面里看到的名称或别名，不用记 ID。

## 模板

```text
按本项目的标准视频流程做一条新视频（先读 AGENTS.md 和 .agents/skills/ecommerce-video-studio/SKILL.md）。
执行规则：
1. 商品、人物、场景、材质一律用 GET http://127.0.0.1:4173/api/library/entities/resolve?q=<名称或别名> 取参考图、用途和锁定文字，不要自己拼路径或手抄比例；重名会返回候选，必须问我，不要替我选。
2. 把返回的 warnings 原样告诉我（待确认的实体、没有佩戴参考、缺失图片）；不得自己编造人物、尺寸或卖点。
3. 先给我 2–3 个不同方向，推荐一个，我确认后再写口播和分镜。
4. 每镜必须有原生口播或画外旁白；车内画面一律停稳状态，不做安装、拉扯动作。
5. 落盘到 production/jobs/<job-id>/ 并用 .agents/skills/infinite-canvas-json-build/SKILL.md 建好画布，把画布链接给我。
6. 到此为止，不提交任何生成；付费生成需要我另行确认。

【任务基础】
品类：【安全带护肩套（默认）/ 包包挂饰（草稿，需先补商品资料）】
形式：【多镜头 UGC（默认）/ 单镜头口播 UGC / 多镜头 TVC】
时长 / 画幅：【例：13 秒，9:16；可留空，AI 按形式建议。单镜 1–15 秒】
交付到哪一步：【① 只出方向+脚本+分镜表 / ② 再建好 job 文件和画布（默认） / ③ 再做批量预检（仍不提交生成）】

【出镜商品】
商品：【名称或别名，可多个；两款同框请标位置，例：电玩款在右、粉裤噜妹在左。新品没登记就写“新品：名字”并附原图路径，不用先登记】
商品状态：【已装在安全带上（写主驾/副驾） / 手持 / 桌面或独立摆放 / 挂在无人的织带上】
缺佩戴参考图时：【先停下来，给我对应的生图预设让我生成 / 借同尺寸款的几何先出提示词（默认）】

【人物与场景】
人物出镜：【否 / 是】
人物：【素材库里的人物名称；多人写分工；写“AI 帮我选”则只能从已登记人物里选并说明理由】
口播方式：【对镜口播 / 画外旁白】
场景：【例：主驾位分享、副驾位展示、后排双人对比、手持展示、桌面展示】
车厢：【默认素材库里的“中国左舵奔驰轿车内饰”；写别的须是素材库里已有的场景】

【内容方向】
目标受众 / 使用情境：【例：通勤女性车主，下班后随口分享】
剧情主题 / 钩子：【可留空，AI 出方向】
主观卖点：【体感描述，例“摸起来软”；不填 AI 就不写卖点。功效、安全类宣称一律不写，除非附依据】
语气 / 人设：【例：轻松、不推销、像朋友分享】
结尾：【例：自然收尾，不接硬广；或写具体一句 CTA】
参考视频：【可选，路径或链接】

【备注 / 禁止项】
【例：这次只有女主一人出镜，不要带出男主；不要出现某款】

—— 以下留空，AI 填 ——
1. 解析结果：商品 / 人物 / 场景 / 材质 → 素材库实体、使用的参考图及用途、warnings
2. 方向（2–3 个）和推荐
3. 口播全文
4. 分镜表（镜号、时长、画面、对白、机位、结束状态、参考图）
5. 参考图缺口及处理建议
6. job 目录、画布链接
7. 需要我确认的事项
```

## 填写示例

```text
品类：安全带护肩套
形式：多镜头 UGC
时长 / 画幅：13 秒，9:16
交付到哪一步：②
商品：帕恰狗（粉格围兜款）
商品状态：已装在安全带上（主驾）
缺佩戴参考图时：先停下来，给我生图预设
人物出镜：是
人物：都市女性 A
口播方式：对镜口播
场景：主驾位分享
车厢：默认
目标受众 / 使用情境：喜欢可爱小物的年轻女车主，停车后随口分享
主观卖点：玩偶软软的，耳朵很可爱
语气 / 人设：轻松，不推销
备注：只有女主一人
```

## 说明

- **商品不必先登记**：登记只在同一款会反复出现时才有价值；没登记的新品直接附原图即可。
- **重名**：写“帕恰狗”会匹配两款，AI 会问你是围兜款还是护目镜围巾款。
- **座位**：副驾镜头 AI 会带 `seat=passenger` 取副驾佩戴参考；没有登记就会提示并退回主驾参考，需要在提示词里单独写明肩带镜像方向。
- **待确认的人物**（如“水豚情侣款女主”）可以用，但 AI 会提醒它不是已批准资产。
- 画布搭好后，在画布里改提示词和参考图，再由你决定是否提交生成。
