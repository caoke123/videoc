## 工作台分镜资产生成与回填

- 参考图左右移动按钮应位于缩略图下方，使用 20px 按钮和清晰箭头，不遮挡图片；深浅主题均可辨认，首尾边界禁用、替换和删除操作仍正常。

- 生成结果卡片保持现有列宽，按原图比例自适应高度，取消固定 3:4 黑边；9:16 原图完整显示，点击可放大，不改变生成尺寸。等待和失败占位卡片仍使用 3:4。图片名称与可复制 ID 分开展示。
- 新生成图片不再截取英文提示词作为名称；Agent 传入中文名称时沿用，否则默认「生成图片-序号」，记录标题采用对应中文名称或「图片生成」。已有标题不自动重命名，用户仍可手动编辑。
- 左侧生成记录标题可通过编辑图标修改并持久化，刷新后保留；修改标题不改变提示词、图片名称或图片 ID，编辑时不应误触记录预览。

- 在图片节点的提示词面板点击「工作台生成并回填」，应沿用节点模型、尺寸、提示词和上游参考图；生成完成后更新原节点，保留名称、中心和连线，多张成功结果成为备选。
- Agent 调用 `workbench_image_generate` 可传 `name` 和 `target:{canvasId,nodeId}`。通过 `generation_get_status` 查看 imageIds 与 backfill（applied/skipped/failed），工作台完成一批后再提交下一镜头。
- 新生成的图片应显示可复制的 `img-UUID` 与名称，下载文件名使用该 ID。图片文件与索引保存到 `production/generated-images/`，刷新或换浏览器后可通过 `workbench_image_results` 按 ID、名称或 taskId 查询。
- 查询结果的 `{type:'generated',imageId}` 可作为工作台参考图，或通过 `canvas_insert_image_nodes` 插入画布；保存到「我的素材」后仍应保留生成图片 ID。
- 生成过程中手动上传、从资产库换图、启动新任务或删除目标时，旧结果不得覆盖或重建节点；图片保留供查询，回填状态应明确报告。
- 参考图读取失败时必须停止，不得静默丢失参考图后继续生成；无参考图的任务不得沿用上一次任务的参考图。
- 两个标签页打开同一画布时，接收回填后不应互相重复保存。回填与视口保存重叠时，两者都应保留。
- 本地上传、「我的资产」和共享素材库填入入口继续可用；删除工作台历史不会删除服务端生成图片。新增编号针对新生成结果，不迁移已有历史。
- 生成仍由打开的生图工作台页面执行，生成期间需保持页面打开；本地执行器和 Canvas Agent 更新后需重启，前端浏览器交互与实际模型生成待用户验收。

The current release needs manual verification in these areas:

- Canvas image previews: canvas image nodes, the left element list, the node reference bar, my-assets cards, the asset picker, image workbench result cards and history thumbnails, and the image/video workbench reference strips all render from a preview capped at a 768px long edge, so image-heavy views no longer decode the originals. Turning it on should reveal the `npx @basketikun/canvas-proxy@latest` command (with `--port` appended when a non-default port is configured), a copy action, and an address field defaulting to `http://127.0.0.1:23210` that normalizes a missing scheme and trailing slashes on blur.
